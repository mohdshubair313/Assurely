# Security reporting

Assurely is under active development. No supported-release matrix or security
response SLA has been published.

For a suspected authorization bypass, exposed secret or customer-data leak, use
the repository's private vulnerability reporting feature if enabled. Otherwise,
contact the repository owner through a private channel listed on their profile.
No dedicated security email is currently documented here.

Do not publish credentials, customer records, private documents or working exploit
details in a public issue. Share affected code/version, impact and a minimal
synthetic reproduction privately. Ordinary non-sensitive bugs can use the issue
tracker if enabled.

Deployment credentials, identity-provider setup, advisor permissions, migration
review and source approval remain operator responsibilities. Development Compose
credentials and synthetic seeds are not a production deployment configuration.
